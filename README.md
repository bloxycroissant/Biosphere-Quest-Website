## 🚀 Overview

**Biosphere Quest** is a personal full-stack web application project created for Grades 1 through 6 students, giving young learners an engaging, browser-based window into learning. While studying foundational subjects, children learn and track their progress in areas such as Basic Counting, Addition & Subtraction, Shapes, Fractions, and Elementary Science (Living Things, Weather, Space). Built for desktop, laptop, and tablet browsers with no downloads required, the platform combines structured course modules with gamified activities, a study scheduler, daily streaks, and weekly leaderboards to encourage daily study habits and help parents/guardians track progress.

## 📚 Educational Framework & Philosophy

The web platform is structured around constructivist learning theories and gamification mechanics tailored for young learners:

* **Curriculum Compliance:** All questions, concept hurdles, and difficulty levels mirror the official **DepEd MATATAG Curriculum** for Grades 1 through 6.

* **Scaffolding & Progression:** Adapts from basic counting, pattern recognition, and ecological awareness (Grade 1) to advanced algebraic equations, geometry, fractions, and ecological equilibrium (Grade 6).

* **Positive Reinforcement Loop:** Continuous positive reinforcement ensures students keep working even when encountering errors, with no harsh system shutdowns for low scores.

## 🕹️ Complete Web App & Game Mechanics

### Handled Core Mechanics

* **Lessons & Quizzes (Courses):** Students choose their grade level (Grades 1–6) and subject (Math or Science) to study bite-sized chunks of instruction (Counting and Number Sense, Shapes and Patterns, Addition and Subtraction, Fractions, Time and Measurement).

* **Mini-Game Challenges (Games):** Browser-playable challenges including Word Scramble, Number Ninja, and Codebreaker.

* **Study Planning:** Features weekly revision sessions and daily learning streaks accessible across devices.

### Player Controls and Interactions

* **Responsive Navigation:** Clicking top/side navigation links or responsive mobile menu tabs (Home, Courses, Games, Profile).

* **Grade Filter Chips:** Interactive buttons to select grade levels (Grade 1 to 6) and filter subjects.

* **Keyboard & Mouse/Touch Input:** Typing answers via keyboard (e.g., unscrambling lesson titles, entering profile info) or clicking/tapping interactive UI elements.

* **Interactive Controls:** Answer selection, quiz starts, toggling days in the study schedule, and claiming profile badges.

## 📈 Progression, Mastery Logic & Scoring Rules

### Levels & Difficulty Scaling

* **Curriculum Levels:** Grade 1–3 (Primary / Key Stage 1) and Grade 4–6 (Intermediate / Key Stage 2).

* **Challenge Levels:** Easy (Grades 1–2), Medium (Grades 3–4), Hard/Master (Grades 5–6).

* **Difficulty Tiers:** Easy, Medium, Hard, and Impossible. Advanced tiers feature shorter time limits, fewer try limits, and harder problems.

* **Progressive Stage Progression:** Unlocking Stage 1 (Basic Concepts) automatically unlocks broader curriculum stages like Stage 2 (Intermediate Concepts). Replayability is supported anytime to improve accuracy scores, raise XP, and unlock achievement badges.

### Daily Quiz Proportional System (30 XP per Correct Answer)

* **5/5 (100%):** 150 XP

* **4/5 (80%):** 120 XP

* **3/5 (60%):** 90 XP

* **2/5 (40%):** 60 XP

* **1/5 (20%):** 30 XP

* **0/5 (0%):** 0 XP

### Win, Loss & Retry Conditions

* **Pass Conditions:** Complete daily quizzes or mini-game stages within the 3-minute time limit to gain XP, level up progress, and climb the Weekly Leaderboard podium (Top 1, 2, and 3).

* **Failure Conditions:** Wrong answers or missed time limits reduce remaining attempts or end the ongoing session. Abandoning a running puzzle or timing out awards +0 XP, requiring a retry to earn higher-tier achievement badges.

## 📋 Rules for Using the Web Application

* **Account & Access:** Users can register via the web portal, log in using email/password or Google authentication, and configure their grade level and profile preferences.

* **Curriculum Progression:** Users can browse lessons by grade level (Grades 1–6) or subject (Math/Science) directly in their browser to maximize XP.

* **Mini-Game Rules:** Mini-games support `'all'`, `'easy'`, `'medium'`, `'hard'`, and `'impossible'` settings. Refreshing, navigating away, or abandoning active quizzes/games before completion will not award points.

* **Scoring & Streak Retention:** XP is credited immediately upon successful answer submission. Daily streaks increase when students complete 1 or more lessons or daily challenges every 24 hours; missing a day resets the streak to 0.

* **Leaderboard Rules:** Ranks are computed weekly based on total XP collected over 7 consecutive days.

## 🛠️ Technical Architecture & Tech Stack

* **Frontend Framework:** **ReactJS (React DOM)** powered by **Vite** for fast development builds and optimized production bundling.

* **Programming Language:** Modern **JavaScript (ES6+)** with `.jsx` component architecture and **ESLint** code quality enforcement.

* **Web Audio Engine:** HTML5 Web Audio API / `use-sound` integration handling low-latency interactive sound effects across modern browsers.

* **Styling & Animations:** Responsive CSS / Tailwind CSS paired with smooth CSS transitions and React motion libraries for desktop and mobile browser compatibility.

## ⚙️ Getting Started & Installation

To run **Biosphere Quest** locally on your development machine:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/biosphere-quest-website.git
   cd biosphere-quest-website
   ```

2. **Install project dependencies:**

   ```bash
   npm install
   ```

3. **Start the Vite development server:**

   ```bash
   npm run dev
   ```

4. **Launch in your web browser:**

   * Open your preferred browser (Chrome, Edge, Firefox, or Safari) and navigate to the local URL shown in your terminal (typically `http://localhost:5173`).
